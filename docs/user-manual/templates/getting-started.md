# Getting Started with Templates

Templates define the standard procedure the AI follows to generate a case's task schedule. There
are two kinds: **built-in templates** covering common Australian visa subclasses (e.g. Student
500, Skilled 190, Partner 820/801, Visitor 600, Graduate 485), and **custom templates** you create
yourself.

## Browsing templates

Templates are shown as cards, grouped into **Built-in Templates** and **Custom Templates**. Each
card shows the visa subclass (if set), a short description, and — if the template has predefined
steps — a **N steps** toggle you can expand to see the full step list.

## Creating a custom template

1. From the sidebar, open **Templates** and click **New Template**.
2. Give it a **Template Title** (e.g. "190 Visa Application — Standard").
3. Write a **Process Description** describing the steps in plain language — this is what the AI
   reads when generating a task schedule for a case that uses this template, so be as specific as
   you'd like the generated tasks to be.
4. Click **Save Template**.

Your new template then appears under **Custom Templates** and is selectable from **New Case** the
same way a built-in template is.

## Deleting a template

Custom templates have a delete (trash) icon on their card. Built-in templates are marked
**System** and can't be deleted — they're maintained centrally so every user has a consistent
starting set of Australian visa workflows.
