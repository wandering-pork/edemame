# Points Calculator & Evidence Mapper

The **Points Calculator** scores the Australian General Skilled Migration (GSM) points test for a
case and, for every criterion you claim, shows whether the case file actually contains a document
that proves it. It replaces the personal spreadsheet most agents keep for points-tested visas.

Open it from a case's **Workspace** tab, under **Tools → Points Calculator**.

## What it covers

The calculator scores the points-tested subclasses **189** (Skilled Independent), **190** (Skilled
Nominated) and **491** (Skilled Work Regional). Pick the table you want at the top right of the
tool — if the case's visa subclass is one of those three, it is selected for you.

Criteria covered: age, English language ability, skilled employment (overseas and in Australia),
educational qualifications, specialist (STEM) education, the Australian study requirement,
credentialled community language, study in regional Australia, partner skills, Professional Year,
and — depending on the subclass — State/Territory nomination or regional nomination/family
sponsorship.

Overseas and Australian skilled employment are scored separately but the combined award is capped
at 20 points; the tool applies that cap and tells you when it has.

## Claimed, Proven, Outstanding

The three running totals along the top are the point of the tool:

- **Claimed** — what the client says applies to them: the band you select for each criterion.
- **Proven** — the claimed points that are backed by at least one document linked from **Case
  Files**. A criterion becomes Proven the moment you link a file to it.
- **Outstanding** — claimed points with no evidence linked yet. This is your to-do list before
  lodgement.

A badge next to the totals tells you whether the claimed total reaches the 65-point minimum needed
to submit an EOI.

If a file you had linked is later deleted from Case Files, the criterion goes back to Outstanding
automatically and the tool says so — a points claim can never keep looking "proven" on the strength
of a document that no longer exists.

## Claiming a criterion and linking evidence

For each criterion:

1. Choose the band the client qualifies for from the dropdown. Choose *Nothing claimed* to leave it
   out of the total.
2. Add a **working note** if it helps — dates, employers, test scores. Notes appear on both exports.
3. Link the evidence. Files already in Case Files whose **Document Type** matches the criterion (for
   example an English test result for the English criterion, payslips and reference letters for
   skilled employment) are offered as one-click suggestions. Use **Link another file…** to pick any
   other file on the case. Click the **×** on a linked file to unlink it — the file itself stays in
   Case Files.

The tool never links evidence by itself. Suggestions are shown, and you decide what actually proves
a claim.

Each criterion has a **Source** link showing what the point values are based on.

## Exports

Two outputs, both from the footer:

- **Download PDF breakdown** — the full criterion-by-criterion breakdown: points claimed, proof
  status, linked evidence (or what is still needed), the running totals, and the source for each
  value. **Add PDF to Case Files** files the same PDF on the case, tagged `PTSCLM`.
- **Cover letter summary** — a shorter, cover-letter-shaped points summary of the kind that
  accompanies an EOI or nomination lodgement: criterion → points claimed → evidence reference →
  total, with anything not yet evidenced listed separately. Copy it or download it as a text file.

Everything is saved as you work — there is no separate Save button.

## Important limits

- The points table built into this tool is **authored reference data, not a legal source**. Points
  values are amended by legislative instrument from time to time. Check the current Department of
  Home Affairs points tables before relying on any total for a lodgement.
- Points are assessed by the Department **at the time of invitation**, not the day you fill this in.
  Age bands and test validity in particular can change between EOI and invitation.
- Both exports are **drafts for a human to review, edit and sign**. Neither is submission-ready.
- The tool does not read facts out of your documents. Linking a payslip to a skilled employment
  claim records that you have evidence for it; it does not verify the number of years claimed.
